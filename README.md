# НПК ЭКОЛОГ — корпоративный сайт

Сайт компании «НПК ЭКОЛОГ». Сфера деятельности — водоподготовка, оборудование, технологии очистки воды.

## 🚀 Запуск проекта

### 1. Установка зависимостей

npm install

### 2. Режим разработки

npm run dev

### 3. Сборка для продакшена

npm run build

Собранный сайт появится в папке dist/

### 4. Предпросмотр собранного сайта

npm run preview


## 🛠 Технологии

- **Vite** — сборщик проекта
- **HTML** + **CSS** — вёрстка
- **JavaScript (ES Modules)** — интерактивность
- **vite-plugin-html-include** — переиспользуемые блоки (header, footer, модалка, карта сайта)

## 📌 Важные особенности

Абсолютные пути — все ссылки в HTML начинаются с / (например, /technologies/). Это гарантирует корректную работу на любой глубине вложенности.

Партиалы — общие блоки вынесены в partials/ и подключаются через <include src="/partials/header.html">.

Корень сайта — папка src/ (настроено в vite.config.js).
